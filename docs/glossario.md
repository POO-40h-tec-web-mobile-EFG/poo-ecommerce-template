# 📖 Glossário: palavras novas

## Programação Orientada a Objetos

| Palavra | O que significa | Exemplo na loja |
|---|---|---|
| **Classe** | O "molde" ou a "receita" de alguma coisa | A classe `Product` |
| **Objeto** | Uma coisa criada a partir do molde | Um notebook de R$ 3.500 |
| **Atributo** | Uma característica do objeto | `name`, `price` |
| **Método** | Uma ação que o objeto sabe fazer | `total()` do carrinho |
| **Construtor** | O método `__init__`, que monta o objeto quando ele é criado | `Product("Notebook", 3500)` |
| **Encapsulamento** | Proteger os dados do objeto para ninguém mudar de qualquer jeito | Impedir preço negativo |
| **Herança** | Uma classe que aproveita tudo de outra | `Customer` herda de `User` |
| **Polimorfismo** | O mesmo método funcionando de jeitos diferentes | `calculate_total()` no Pix e no boleto |

## Git e GitHub

| Palavra | O que significa |
|---|---|
| **Git** | Programa que guarda o histórico das mudanças do seu código |
| **GitHub** | Site onde o seu código fica guardado na internet |
| **Repositório** | A pasta do projeto, com todo o histórico |
| **Template** | Um modelo pronto para criar novos repositórios |
| **Clone** | Baixar o repositório do GitHub para o seu computador |
| **Commit** | Uma "foto" do código naquele momento, com uma mensagem |
| **Push** | Enviar os commits do computador para o GitHub |
